# 자료 안내

이 저장소에는 **인물별 자료를 넣지 않았습니다.** 논문의 모든 표는 `data/main/`(주 분석 11,829명)과 `data/full_sample/`(전체 12,265명)에 집계 결과로 들어 있습니다.

## 왜 넣지 않았나
분석 입력은 위키데이터에 등재된 한국 연예인의 출생일과 직업입니다. 위키데이터의 생존 인물 정책(WD:LP)은 생존 인물의 값은 널리 알려졌거나 본인이 공개한 경우에만 넣도록 하고, 생년월일 속성(P569)에는 "사생활을 침해할 수 있는 속성" 표시가 붙어 있습니다. 표본의 70%는 위키백과 언어판이 3개 미만인 사람이고 미성년 출생 연도도 들어 있어서, 이름을 빼더라도 인물별 생년월일을 다시 공개하지 않기로 했습니다. 제출용 비공개 패키지에는 원자료가 들어 있습니다.

## 코드를 돌리려면
`analysis/build.py`는 아래 형식의 CSV를 입력으로 받습니다. 위키데이터에서 같은 조건으로 직접 내려받아 `data/query_raw.csv`로 저장하면 README의 순서대로 실행됩니다.

| 열 | 내용 |
|---|---|
| `p` | 위키데이터 항목 URL |
| `dob` | 출생일(`YYYY-MM-DDT00:00:00Z`) |
| `prec` | 날짜 정밀도(일 단위만 사용, 값 11) |
| `occLabel` | 직업 이름(한 사람이 여러 줄) |

조건: 국적이 대한민국이고, 직업이 아래 43종 중 하나이며, 출생일이 일 단위로 기록된 사람(2026-10-08 질의, 20,869행·고유 인물 12,265명).

직업 43종: MC(음악), TV 사회자, VJ, audiobook narrator, baseball commentator, bass singer, beatboxer, chanteuse, child singer, esports commentator, game show host, jazz singer, opera vocal coach, owarai tarento, soccer commentator, video game actor, vocalist, voice teacher, 가상 아이돌, 가수, 기상 캐스터, 뉴스 캐스터, 래퍼, 뮤지컬 배우, 배우, 성악가, 성우, 성인용 비디오 배우, 쇼핑 호스트, 스턴트 배우, 스턴트 코디네이터, 스포츠 해설가, 스포츠캐스터, 싱어송라이터, 연극 배우, 영화 배우, 오페라 가수, 일본의 성우, 코미디언, 코스플레이어, 텔레비전 배우, 팝 가수, 포르노 배우.

위키데이터는 계속 바뀌므로 다시 내려받으면 사람 수와 값이 달라질 수 있습니다. 유명도(`fame_raw.csv`: 항목 URL과 위키백과 언어판 수, 3개 이상만)와 P6 집단 목록(`looks_group_raw.txt`)도 같은 방식으로 직접 만들어야 하며, 각 스크립트의 인자 설명을 참고하세요.
