# 사주, 없어도 괜찮아

원하는 직업(배우, 가수, 코미디언·사회자)에 어울린다고 하는 사주 조건이 일반인에게 얼마나 흔한지, 내 생년월일은 해당되는지 보여 주는 앱입니다.

- 논문: 원석연 (2026). 사주 조건은 연예인의 직업과 성취와 관련이 있는가: 한국 연예인 11,829명의 출생일로 본 달력 기대 분포와의 비교
- 논문 저장소: https://github.com/Nugury-code/saju-celebrity-test

## 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다. 설치, 로그인, 서버가 필요 없습니다.

## 환경 변수

필요한 환경 변수 없음. AI 서비스 키나 비밀값을 쓰지 않습니다.

## 데이터

- 1921~2017년 모든 날짜의 사주 조건 표를 `index.html` 안에 넣었습니다. 논문의 사주 계산 코드(한국천문연구원 절기 시각 기준 만세력)로 만든 값이며, 실제 사람의 정보는 없습니다.
- 입력한 생년월일은 브라우저 안에서만 계산하고 저장하거나 보내지 않습니다.
- 일반인 비율은 달력 날짜 전체에서 조건이 성립하는 날의 비율입니다. 식신·상관, 도화살은 논문의 정의 그대로이고, 상관·편인은 논문과 같은 방법으로 직접 계산했습니다.
- 월이 바뀌는 날(절기 당일)은 그날부터 새 달로 계산합니다.

## 한계

- 월지·일지 본기로 정한 조건만 봅니다. 시주는 보지 않습니다.
- 직업별 "어울린다고 하는 조건"은 논문이 인용한 연예인 연구를 따랐습니다.
- 사주를 저격하려는 앱이 아니라, 사주를 재미로 즐기는 사람이 만든 앱입니다.
